# 電子印メーカー（DenshiIn）

認印・日付印・角印の電子印（透過PNG）を作成するツールです。タスクバーの通知領域に常駐します。

## 必要なもの
- Python 3.9 以降 と Flask（追加インストール不要。常駐アイコンは Windows 標準機能で表示）

## 起動
- `start.bat` を実行 → 専用ウィンドウが開き、通知領域に赤い「印」アイコンが常駐します
- ウィンドウを閉じても常駐は続きます。アイコンを左クリックで再表示
- アイコンを右クリック：開く / 保存フォルダを開く / Windows 起動時に常駐する / 終了

## 使い方
1. 上部のタブで種類（認印・日付印・角印）を選ぶ
2. 氏名などを入力 → 右側にリアルタイムでプレビュー
3. 「コピー」（Ctrl+Enter）→ Excel・Word などに Ctrl+V で貼り付け
   または「PNG保存」（Ctrl+S）で保存フォルダに保存
4. よく使う印は右上「＋ 登録」で登録 → 上部からワンクリックで呼び出し

## データの保存場所
- 設定・登録した印：`%APPDATA%\DenshiIn\state.json`
- PNG の保存先（初期値）：`ピクチャ\電子印`（詳細設定で変更可）
- ログ：`%APPDATA%\DenshiIn\app.log`

## 補足
- 使用ポート：127.0.0.1:8765（変更は環境変数 `DENSHIIN_PORT`）。PC内からのみ接続可能です
- 書体は PC にインストール済みのものだけが表示されます（Office 付属の「HG正楷書体-PRO」があると印鑑らしくなります）
- 社内規程で電子印の使用範囲が定められている場合は、それに従って使用してください
