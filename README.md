# PonStamp（電子印メーカー）

認印・日付印・角印の電子印（背景が透明な PNG）を作る Windows のアプリ（`PonStamp.exe`）です。タスクバーの通知領域（右下）に常駐し、
登録した印は右クリックのメニュー（通知領域のアイコン、またはデスクトップ・フォルダの何も無い所）から**窓を開かずに 2 手でコピー**できます。Excel・Word・PowerPoint・PDF 編集ソフトなどに貼り付けて使います。

- **exe 1 つで動きます。** Python・Flask・ブラウザは要りません（ポートも開きません）。画面は exe に入っています
- **貼り付け先で指定の大きさ（mm）になります。** 保存・コピーする PNG に解像度（dpi）を書き込みます
- **配る人が決めた版に、各 PC が自動でそろいます**（[更新のしかた](#更新のしかた)）

## はじめて使う

1. 配る人から渡された**配る入口のアドレス**（例 `\\fs01\共有\Releases\PonStamp\PonStamp.exe`）か、配られた ZIP を展開した `PonStamp.exe` をダブルクリックします。
   アプリがこの PC の `%LOCALAPPDATA%\PonStamp\app` へ写って、そちらで開きます（尋ねません。数秒）。以後は共有につながっていなくても開けます。
2. 「デスクトップとスタートに PonStamp のショートカットを作りますか？」と出たら「**作る**」を押します（「今回は作らない」「今後たずねない」も選べます。
   あとからは「設定」→「起動」の「ショートカット」から）。
3. Windows 起動時に常駐させたいときは「設定」→「起動」の「常駐」を入れます（通知領域に出るだけで、窓は開きません）。

- 前の形（Flask 版「電子印メーカー（DenshiIn）」）を使っていた PC では、登録した印・最後の印・保存先を初めての起動で引き継ぎます。
  前の形がスタートアップに置いた常駐の `.vbs` は外し、exe の常駐に置き換えます。
- 共有の exe（や共有を指すショートカット）を開いても、すぐこの PC の物が開きます。ショートカットは起動のたびに確かめ、共有を指す物はこの PC の物に直します。

## 使い方

1. 種類（認印・日付印・角印）を選び、氏名などを入れます。右にすぐ映ります（日付印は、年の書き方と区切り「. / - 年月日」も選べます）
2. 色・大きさ・字の大きさを選びます。大きさはスライダーで動かすか、下の目盛り（よく使う大きさ）を押すか、mm を打ち込みます。
   字の大きさは 100% が標準で、小さくも（60% まで）、認印・日付印は少し大きくも（110% まで）できます（細かい調整: 書体・枠と字の太さ・かすれ・傾き）
3. 「**コピー**」（`Ctrl+Enter`）→ 貼り付け先で `Ctrl+V`。または「**PNG保存**」（`Ctrl+S`）で保存先に保存します
4. よく使う印は「＋ 登録」で登録すると、上の並びからワンクリックで呼び出せます

**通知領域から使う**: アイコンを左クリックで窓が出ます。右クリックのメニューで、登録した印（と、いま作っている印）を押すとそのままコピーされます
（右下に「コピーしました」と出ます）。窓の × は閉じずに隠すだけで、終了は右クリックの「終了」です。2 回目に開くと、前の窓が前に出ます。

**デスクトップ・フォルダの右クリックから使う**: 常駐している間は、デスクトップやフォルダの何も無い所を右クリックすると「電子印をコピー（PonStamp）」が出て、
その下の登録した印を押すとそのままコピーされます（Windows 11 では「その他のオプションを確認」（Shift+F10）の中にあります）。終了すると消えます。

### 大きさと解像度

- 大きさ（mm）は印影の直径（角印は一辺）です。解像度（「設定」→「保存とコピー」。300・600・1200 dpi）は、きめの細かさです。
- 保存した PNG には解像度が書いてあるので、Word などに**ファイルから挿入**すると指定の mm になります（600 dpi・10.5mm の認印は 248px で、10.5mm として入ります）。
- **コピー**では、Windows のクリップボードへ「PNG」（透明つき・解像度つき）と「ビットマップ」（解像度つき）の 2 つの形で置きます。
  貼り付け先がどちらの形と解像度を読むかはアプリによります。Office の各アプリで実際に mm どおりに貼られるかは、まだ確かめていません。
  大きさが合わないときは、PNG 保存してファイルから挿入してください。

## 設定

画面右上の「設定」で変えます。

| 項目 | 中身 |
|---|---|
| 保存とコピー | PNG の保存先（「参照…」で選ぶ・「開く」で開く）・解像度 |
| 起動 | Windows 起動時に常駐する・ショートカットを作る |
| 更新 | いまの版・状態・今すぐ確かめる・更新の置き場 |
| 配布（配る人向け） | 版を置く・配る版を選ぶ・前の版に戻す・消す・新しい PC へ渡すアドレス |
| このアプリについて | 版・更新履歴・作業場所 |

## 更新のしかた

**使う人**: 何もしなくて構いません。

1. アプリが起動の直後と 30 分ごとに更新の置き場を確かめ、配る版がこの PC に無ければ裏で取り込みます（指紋を確かめ、中身がこのアプリのその版かを確かめてから）。
   そのあいだも今の版で使えます
2. 取り込むと、画面に「新しい版 〈版〉 があります」と出ます（通知領域の右クリックにも「新しい版に更新する」）。押すとその版で開き直します
3. 押さなくても、次に開いたとき（Windows の起動時も）その版で開きます。閉じている間に配られた版も、1 回開くだけで入ります
4. 新しい版の画面が出なかった（起動できなかった）ときは、次に開いたとき前の版へ戻し、その版はもう取り込みません

**配る人**: 「設定」→「配布（配る人向け）」で、① → ② の順に進めます。

1. **① 版を置く**: GitHub の Releases から `PonStamp-<版>-windows.zip` を取り、「ZIP から版を置く…」で選びます。中身（このアプリの物か・版・exe）を確かめてから、
   置き場のアプリのフォルダの下の `versions` に、版のフォルダと `release.json` を作ります。**置いただけでは配りません**
2. **② 配る版を選ぶ**: 試してから、一覧の「この版を配る」を押します。各 PC は起動したとき・30 分ごとに確かめ、開き直したときにその版になります
3. **前の版へ戻す**: 一覧の「この版に戻す」を押すだけです（各 PC も前の版を取り込み、開き直したときに戻ります）
4. **版を消す**: 「消す」→「もう一度押すと消す」（4 秒で元に戻ります）。配っている版は消せません
5. **新しい PC へ**: 「新しい PC へ」のアドレス（配る入口）を「アドレスをコピー」で写して渡します

更新の置き場は「設定」→「更新」の「更新の置き場」で決めます（「;」で区切って候補を複数・`%USERNAME%` などの環境変数も使えます。BOX の見え方が PC で違っても探し直します）。
配る入口から入れた PC は、その入口の置き場を自動で使います。置き場のフォルダに書ける人（共有・BOX の権限）が、版を置き・配れます。

```
\\fs01\共有\Releases\           ← 更新の置き場（「設定」→「更新」の「更新の置き場」）
  PonStamp\                     ← アプリのフォルダ（最初に版を置くと作る。名前は「配布」で決められる・既定はアプリの名前）
    distribute.json             ← 配る版（「この版を配る」で書く）
    PonStamp.exe・app.json      ← 配る入口（配る版の exe と名乗り。新しい PC へはこのアドレスを渡す）
    versions\                   ← 版を置くフォルダ（名前は「配布」で決められる・既定 versions）
      1.0.1\                    ← 版のフォルダ（版を置くたびに 1 つ作る）
        release.json            ← このアプリの版だという印・版・ZIP の名前・指紋
        PonStamp-1.0.1-windows.zip
```

「設定」→「配布」には、この形がいまのアドレスと名前で図になって出ます（まだ無いフォルダは「最初に…すると作ります」と出ます）。
フォルダの名前を変えると、次に置く・配るときからその名前で作ります。前に置いた版（1.1 までのアプリのフォルダの直下に置いた版も）は、そのまま見つけて使えます。

ZIP の中は `PonStamp\PonStamp.exe`・`PonStamp\app.json`（名乗り: 目印・名前・版）・`PonStamp\README.md` です。
同期が終わる前の ZIP は指紋が合わないので取り込みません。配った置き場の中身は各 PC が書き換えないので、ほかの人が使っていても止めません。

## データの置き場

すべてこの PC の `%LOCALAPPDATA%\PonStamp` にあります（利用者ごと）。

| 場所 | 中身 |
|---|---|
| `state.json` | 登録した印・最後の印・保存先・更新の置き場 |
| `app\` | この PC へ写したアプリ（ショートカットと常駐はここの exe を指す） |
| `desktop\` | 版ごとに写した exe（動いている窓はこちら。だから `app\` を入れ替えられる） |
| `update\` | 取り込んだ次の版・直前の版の控え・起動できなかった版の記録 |
| `logs\app.log` | 記録（起動・更新・写し・ショートカット） |

PNG の保存先の既定は `ピクチャ\電子印` です。常駐は `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` の「PonStamp」に入ります（管理者の権限は要りません）。
右クリックのメニューは、常駐している間だけ `HKEY_CURRENT_USER\Software\Classes\Directory\Background\shell\PonStamp` に置きます。

## 補足

- 書体は PC に入っている物だけが選べます（Office 付属の「HG正楷書体-PRO」があると印鑑らしくなります）
- 社内規程で電子印の使い方が決められている場合は、それに従ってください
